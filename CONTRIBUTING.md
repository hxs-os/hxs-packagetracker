# Contributing to hxs-packagetracker

hxs-packagetracker is maintained on [github](https://github.com/hxs-os/hxs-packagetracker) -- this document explains how to report bugs and send patches there.

## Reporting Bugs / Requesting Features

Use the [issue tracker](https://github.com/hxs-os/hxs-packagetracker/issues). When filing a bug include:

- Your OS and formula
- Steps to reproduce
- What you expected vs. what happened

## Sending Patches

1. Fork the repo and make your changes on a branch
2. Commit with a clear, scoped message (see "commit style" below)
3. Open a pull request against `main`

## Commit Style

- One logical change per commit
- Imperative, lowercase summary line (`add X`, not `Added X` or `adds X`) -- matches the existing log
- Keep the summary under ~72 chars; use the body for anything that needs more explanation
